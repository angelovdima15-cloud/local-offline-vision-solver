# Local Offline Vision Solver — запуск

## Windows

1. Распакуйте весь `LocalVisionSolver-Windows-x64.zip` в обычную папку с правом записи. Не запускайте EXE прямо из ZIP.
2. Нужны Windows x64 и актуальный драйвер NVIDIA. Целевая видеокарта: RTX 4060 Laptop 8 ГБ. Python, Xcode и сборка исходников на Windows не нужны.
3. С Интернетом один раз запустите `Initial-Setup.cmd`. Он скачает CUDA llama.cpp, Qwen3-VL 8B Q4_K_M и F16 vision projector с проверкой SHA256. Зарезервируйте не менее 15 ГБ свободного места; загрузка занимает несколько ГБ. Прерванную загрузку можно повторить.
4. Запустите `Check.cmd`, затем `Start.cmd`. Разрешите доступ к частной сети, если Windows Firewall запросит его. Не открывайте порт в Интернет.
5. Подключите iPhone к той же Wi-Fi сети. Оставьте окно backend открытым. После первичной установки Интернет для решения заданий не нужен.

`Transport-Demo.cmd` проверяет доставку и карточки без модели; он НЕ решает задания. Обычный запуск — `Start.cmd`.

## iPhone и Apple Watch

`LocalVisionSolver-unsigned.ipa` содержит собранные iPhone и Watch приложения. Перед установкой IPA необходима подпись Apple. Простое открытие скачанного IPA не устанавливает приложение.

Для iPhone с Windows можно попробовать [Sideloadly](https://sideloadly.io/) с собственным Apple Account; бесплатная подпись требует обновления каждые 7 дней. Apple Account используется установщиком, в самом Vision Solver нет входа и облачной обработки. Пароль Apple не передавайте разработчику.

**Установка вложенного Watch приложения таким способом пока не проверена.** Успешная сборка подтверждена Xcode, но сама установка на часы и WatchConnectivity требуют проверки на настоящей паре устройств. Для штатной подписи обоих targets используйте Mac/Xcode; TestFlight требует Apple Developer Program.

После установки: разрешите камеру и локальную сеть, сфотографируйте страницу, подтвердите снимок, добавьте другие страницы и нажмите Solve. Держите приложение iPhone открытым до получения ответа. Ответ доступен на iPhone; при установленном Watch приложении карточки передаются через WatchConnectivity. На активных часах появится ответ, в фоне — уведомление при разрешённых уведомлениях.

## Статус поставки

Это сборка для установки и аппаратной приёмки. Пройдены Python/Swift тесты, Xcode сборки iPhone/Watch и проверка настоящего HTTP в режиме demo. Проверка качества Qwen на реальных заданиях, VRAM/времени RTX 4060 и полный сценарий на iPhone/Watch ещё требуется. Q4_K_M — начальная конфигурация, её преимущество по точности пока не измерено. Сборку нельзя считать принятой в эксплуатацию до этих проверок.

Ошибки модели и рендера сохраняются локально в `sessions`; исходные фотографии также остаются локальными. Полный ответ не сокращается ради времени. Для следующего независимого задания нажмите New Task.
