## Efficient implementation

- Complete authorized work autonomously; ask only when missing information prevents a sound decision.
- Start with the relevant files, symbols, and callers. Use `rg` and bounded excerpts before broad reads.
- Batch independent reads and searches; keep dependent operations sequential.
- Keep generated assets, caches, dependencies, and archived sessions out of routine searches.
- Store long command output in a local log; surface the exit code, relevant errors, and log path.
- Run checks for the changed behavior; expand for affected contracts or a concrete remaining risk.
- Stop optional rechecking after the relevant checks pass. Fix detected failures before reporting completion.
- Use independent agents only when the task authorizes delegation and the work is meaningfully independent.
- Keep explanations and progress updates concise. Report actual verification and any remaining blocker.
- On Windows PowerShell, use `codex.cmd` and `npm.cmd` if `.ps1` wrappers are blocked.
