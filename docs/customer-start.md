# Запуск Vision

1. Запустите переданный `Vision.exe` на Windows 11 x64. Установщик создаёт приложение и ярлык «Vision» для текущего пользователя.
2. В первоначальной настройке проверьте компьютер, выберите каталог данных и нажмите «Продолжить настройку». Нужен Интернет для загрузки runtime и примерно 6,19 GB модели/projector. Мастер проверяет SHA256; пауза и повтор сохраняют `.part` и продолжают загрузку.
3. Если драйвер NVIDIA отсутствует или несовместим, откройте официальный сайт NVIDIA, скачайте подходящий драйвер и выберите «Установить скачанный драйвер». Vision проверяет подпись установщика. Windows может запросить UAC и перезагрузку; после неё откройте Vision и продолжите настройку.
4. Подключите iPhone и ноутбук к одной Wi-Fi сети или подключите ноутбук к iPhone Personal Hotspot. На главном экране обновите QR и откройте его камерой iPhone. Код действует 120 секунд. Это сопряжение доступа в доверенной LAN, а не шифрование HTTP-трафика.
5. Если телефон не подключается, откройте «Настройки сети». Для firewall доступна отдельная кнопка с UAC: она открывает только API для локальной подсети. Модельный порт не открывается.
6. В Safari добавьте все связанные страницы, подтвердите preview, задайте порядок и нажмите «Решить задачу». Оригиналы остаются в исходном качестве. Скачайте PNG, TXT или ZIP. При ошибке подготовки карточек проверенный TXT остаётся доступен; повтор подготовки не вызывает модель.

Лимиты: 12 страниц, 60 MiB на исходный файл, 300 MiB исходников задачи, 64 млн пикселей на изображение. При превышении снимок отклоняется с ошибкой; оригинал не уменьшается автоматически. После настройки внешний Интернет не нужен; рабочая локальная сеть нужна постоянно.

Закрытие окна оставляет программу в трее. Полный выход через меню трея останавливает модель и восстанавливает изменённые настройки питания. Переключатель крышки действует при подключённом питании; батарейное действие крышки не меняется. Настоящий сон и гибернация останавливают обработку. Обеспечьте охлаждение и проверьте режим на конкретном ноутбуке.

Завершённые задачи по умолчанию хранятся 24 часа. Сохраните нужный результат заранее. При отказе IndexedDB Safari покажет, что фотографии не сохранены для reload; не закрывайте вкладку до завершения отправки. Диагностика из desktop не включает фотографии.

Установка приложения не требует Python или CUDA Toolkit. Цель — RTX 4060 Laptop 8 GB; RAM 16 GB, рекомендуется 32 GB. Чистая Windows, реальные задачи Qwen, Safari и закрытая крышка требуют отдельной аппаратной приёмки; demo не решает сфотографированное задание.
