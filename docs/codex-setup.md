## Профили

Файлы установлены рядом с пользовательским `config.toml`; копии для переноса находятся в `tools/codex/`.

| Профиль | Модель / reasoning | Назначение |
| --- | --- | --- |
| `balanced` | Sol / medium | Обычная разработка, Standard |
| `eco` | Luna / high | Небольшие понятные изменения, без подагентов, Standard |
| `sprint` | Sol / medium | Fast, когда важнее ожидание |
| `deep` | Sol / high | Сложные ошибки и архитектура, Standard |

Запуск из каталога проекта в PowerShell:

```powershell
codex.cmd --profile balanced
codex.cmd --profile eco
codex.cmd --profile sprint
codex.cmd --profile deep
```

Обычный запуск `codex.cmd` использует новые пользовательские defaults. Изменение файлов не меняет модель/reasoning уже выполняющегося хода; для них нужна новая CLI-сессия. Выбранные в интерфейсе приложения настройки чата могут иметь собственный приоритет.

Fast быстрее расходует лимиты: 2.5× для включённых подписочных лимитов, 2× для купленных кредитов/Enterprise pay-as-you-go. Поэтому он доступен отдельным профилем. Доступность моделей и Fast зависит от аккаунта и клиента. [Официальная документация Speed](https://learn.chatgpt.com/docs/agent-configuration/speed).

## Быстрые команды разработки

```powershell
rg -n 'clear_context|begin_session' src tests -g '*.py'
.venv\Scripts\python.exe scripts/dev.py outline src/local_vision_solver/inference.py
.venv\Scripts\python.exe scripts/dev.py read src/local_vision_solver/inference.py 45 66
.venv\Scripts\python.exe scripts/dev.py check tests/test_discovery.py
.venv\Scripts\python.exe scripts/dev.py check tests/test_pipeline.py::test_sessions_share_no_previous_images_or_messages
```

Тестовый helper сохраняет весь вывод в `.cache/dev-checks/`, возвращает исходный exit code pytest, показывает краткий итог при успехе и последние 80 строк при ошибке. Полный лог доступен для дальнейшей диагностики. Бюджет вывода Codex — ограничение истории, а не смысловая компрессия.

## Выбор расширений

Для Python-кода в `src` и `tests` используются уже доступный `rg` и встроенный AST Python. Serena полезна при более сложной навигации по связям/большому проекту; её установка здесь пока не подкреплена замером.

Для тестов этого проекта настроены собственный компактный вывод и полный лог. RTK оставлен кандидатом для больших логов и других CLI-команд. Serena, RTK, Context7, браузерные инструменты и агентные фреймворки не подключены автоматически. Они добавляются для конкретной потребности; модель продукта продолжает работать локально через llama.cpp.

Исходники кандидатов: [Serena](https://github.com/oraios/serena), [RTK](https://github.com/rtk-ai/rtk). Заявленная экономия вывода этих инструментов не является измеренной экономией всей разработки.
