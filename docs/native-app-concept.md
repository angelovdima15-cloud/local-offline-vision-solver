# Сохранённая идея приложений iPhone / Apple Watch

Первоначальный замысел сохранён здесь. Native-код, Xcode-проект, IPA, Swift-тесты и старые локальные native-сборки удалены при переходе на локальный сайт. Текущий продукт: Windows + браузер iPhone; Watch в нём не участвует.

## iPhone — камера и контроллер задачи

При открытии сразу камера. Предпочтительная камера — Ultra Wide, максимальное практическое качество JPEG/HEIF без агрессивного уменьшения. После снимка — полноэкранный preview с Retake / Use Photo. Пользователь проверяет резкость, фокус и видимость всей страницы.

После принятия снимка: список Page 1 ✓, Page 2 ✓ и действия Add Page / Solve. Можно менять порядок и удалять страницы. Одна Session содержит все фотографии одной задачи; New Task создаёт полностью независимый контекст.

Ноутбук обнаруживается через Bonjour; статус Connected, ручной IP только как запасной вариант. Передаются session_id, page_count, page_order и исходные изображения. Экран обработки: Uploading → Reading task → Solving → Checking solution → Rendering → Sending to Watch. Upload/polling поддерживают возобновление и идемпотентные повторы.

Результат: полный текст, structured answer и упорядоченные PNG-карточки; ответ доступен на телефоне. Сохранение в Photos опционально. При выключенных часах результат сохраняется на iPhone и передаётся позже. Ошибки: ноутбук не найден, upload failed, модель недоступна, нужен переснимок, Watch недоступны.

## Apple Watch — минимальный просмотрщик

WatchConnectivity передаёт целостный пакет карточек с проверкой размера, порядка и SHA256. Частично доставленный результат не показывается. При получении — haptic в активном приложении или разрешённое локальное уведомление в фоне. Принудительное открытие watchOS app не обещается.

Первая карточка содержит главный результат, остальные — полное решение. Для письменного задания первая карточка начинает текст. Карточки доступны прокруткой/перелистыванием, длинный ответ не обрезается. Новый результат заменяет активный; поздно пришедшая старая задача не заменяет новую. Допустим небольшой recent cache. Сложные ошибки остаются на телефоне.

Часы не запускают модель, не обрабатывают фото и не обращаются к ноутбуку. LaTeX рендерится на Windows в PNG. iPhone↔Watch relay переживает недоступность часов и повторную доставку с подтверждением получения.

## Общие принципы

Qwen3-VL 8B локально на RTX 4060 Laptop 8 ГБ, llama.cpp CUDA. Все страницы анализируются вместе; новый Session очищает контекст. Image quality → чтение/классификация → полное решение → независимая проверка → исправление → карточки. Исходные снимки сохраняются; enhancement только обычными алгоритмами, без генерации символов.

Ответ на языке задания: English, русский, қазақша. Предметы: математика, физика, информатика, IELTS/English, казахский, география на казахском, тесты с выбором ответа и объяснением. Приоритет: правильность, чтение фото, изоляция задач, offline, надёжная доставка, читаемость, скорость, оформление.

Никаких cloud OCR, аккаунтов продукта, телеметрии или удалённого хранения. Internet допускается для первоначальной установки. Native-дистрибуция потребовала бы отдельного решения подписи Apple и проверки настоящих устройств.
